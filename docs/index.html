Pilotez vos machines laser K40, GRBL, Ruida, Moshi et Galvo avec une interface moderne en PyQt6. Intègre une IA de vision pour chutes de matière, du nesting 2D, des générateurs d'incrustation et une télécommande mobile Wi-Fi sans fil.

Installation Rapide

Prêt en quelques secondes sous Windows, macOS ou Linux.

# Cloner le dépôt GitHub
git clone https://github.com/LordMadTrix/MadGravQt.git
cd MadGravQt

# Installer les dépendances
pip install -e .

# Lancer l'interface graphique Qt
python run_qt.py
